# Parity: Selenium `HealthTest` → Playwright `health/health.spec.ts`

Legacy source: `tests/legacy-suites/selenium/src/test/java/com/otterworks/legacy/admin/tests/HealthTest.java`
(supporting: `AdminTestBase.java`, `pages/BasePage.java`, `pages/HealthPage.java`, `pom.xml`; branch `qe/legacy-suites-fixture`).

Stack: real local Compose backend (postgres, redis, localstack, auth, document, file, api-gateway, admin-service) + `ng serve` on :4200 (`/api` proxied to the gateway on :8080). No route mocks; each test registers a fresh gateway user (`adminTest` from `support/admin-session.ts`) and proves the session is the real gateway one (`expectGatewaySession`, plus the Bearer token on the health request), never `AuthService.mockLogin`.

Observed health data on this stack: `GET /api/v1/admin/health/services` → overall `degraded`; auth/file/document `healthy`, collab/notification/search/analytics/audit `unhealthy`, database and redis `healthy` → UI summary **5 Healthy / 0 Degraded / 5 Down**. The Playwright tests compute the expected counts from the live response (same mapping as `AdminApiService.mapHealthServices`), so they do not hard-code stack-dependent numbers.

Legacy run: `ADMIN_BASE_URL=http://localhost:4200 mvn -s frontend/admin-dashboard/e2e/migrated/stack/maven-settings.xml test -Dtest=HealthTest` → Tests run: 3, Failures: 3. `AdminTestBase` never signs in, and `authGuard` redirects `/health` to `/login` (verified: an unauthenticated browser on `/health` lands on `http://localhost:4200/login`, whose only h1 is "OtterWorks Admin").

Playwright run: `npm run test:e2e:migrated -- --grep @selenium-HealthTest`, twice in a row → 3 passed / 3 passed.

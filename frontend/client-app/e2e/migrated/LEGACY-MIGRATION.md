# Combined legacy-suite migration

This combined branch represents all **20 legacy tests**: **15 Selenium** tests (3 login
passes, 11 failures caused by the legacy base never signing in, and 1 vacuous Features
pass) plus **5 Cypress** tests (all passed with backend APIs stubbed). All 20 are kept
or merged; none were dropped. See [CROSSCHECK.md](CROSSCHECK.md) for the settled
cross-check decisions.

Both combined client runs executed 18 tests: 17 regular passes and one expected
failure for TC-SET-003 (`test.fail()`), with zero unexpected failures. Both
combined admin runs passed all 15 tests.

Run the client suite from `frontend/client-app` with
`npx playwright test -c playwright.migrated.config.ts`; run the admin suite from
`frontend/admin-dashboard` with
`npx playwright test -c playwright.migrated.config.ts`.

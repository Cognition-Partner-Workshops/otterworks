# Claims warehouse estate (dedicated SQL pool)

Legacy source for the policy and claims warehouse, plus the frozen window both engines load and the first-pass Snowflake output. The harness in `warehouse-parity/` reads `manifest.yaml` from this folder.

| Folder | Contents |
|---|---|
| `ddl/` | Dedicated pool DDL (distribution and index options are stripped when loading SQL Server 2022 locally) |
| `seed/` | Frozen window, September 2026, regenerated byte for byte by `seed/generate.py` |
| `procs/`, `functions/`, `views/` | Legacy T-SQL objects |
| `iics/` | Mapping exports with SQL overrides, the parameter file and the legacy connection |
| `qlik/` | Producer dashboard load script (three `SQL SELECT` blocks) |
| `first_pass/` | Automated first-pass Snowflake output and its report |
| `manifest.yaml` | Object inventory, waves, how to run each object and how to compare it |

Converted mappings go in `iics/snowflake/` and the converted load script in `qlik/snowflake/`, matching the paths in `manifest.yaml`.

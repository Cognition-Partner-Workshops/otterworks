# Claims privacy

Claims and claimants on PostgreSQL 16, seeded from the claims hub corpus.
Claimant PII is masked for `claims_reader` and plain for `claims_adjuster`,
and a purge with a dry-run mode clears the PII of closed claims. Names are
fixed in [ESTATE.md](ESTATE.md), the rules in
[RETENTION-POLICY.md](RETENTION-POLICY.md), and the examiner answers in
[REPORT.md](REPORT.md).

```sh
NS=me ./run.sh up        # PostgreSQL 16 in Docker; loads shared/compliance-kit/postgres and sql/01..04
NS=me ./run.sh test      # tests/test_access.sql + tests/test_retention.sql
NS=me ./run.sh compare   # queries/claimant_lookup.sql as reader_demo and adjuster_demo, side by side
NS=me ./run.sh down      # stop and remove the container and its volume
```

`sql/02_seed.sql` and `seed/RECONCILIATION.md` are generated by
`python3 seed/build_seed.py`, which reads the read-only fixture branch with
`git archive` at a pinned revision. Never edit either file by hand.

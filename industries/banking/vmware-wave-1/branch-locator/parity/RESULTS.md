# branch-locator parity: VM stand-in vs platform container

- Before: `web-02` from `vm/compose.yaml` (Python 2.7, Flask dev server), `http://localhost:8083`.
- After: image `otterworks/bank-branch-locator:local` in kind (`KIND_CLUSTER=w1-branch-locator`, 2 replicas,
  Kyverno enforcing), Service port-forwarded to `http://127.0.0.1:18083`.
- Same inputs on both sides: Postgres seeded from `data/seed.sql`
  (SHA-256 `d0a85dd227832fd10b71cbaebb9ee4efe0fc38e257293f0eb9be444cdf613756`) and the unchanged geocoder stub
  `vm/geo-stub/geo_stub.py` (SHA-256 `8908d1b9bd85bc8b93b2e2f697e7a181bf70c08bc7546d71823a9278d8507253`),
  both shipped to kind by `deploy/kind-deps/` (generated by `parity/gen-kind-deps.py`).
- Same zone on both sides: `web-02` runs in `Etc/UTC` (`/etc/localtime`); the container sets `BUSINESS_TZ=Etc/UTC`
  and `TZ=Etc/UTC`. `open_now` is compared as-is: each case is sent to both sides back to back and repeated if the
  UTC minute changed between the two requests. Run minute: 2026-11-05T13:21Z.
- Compared per case: HTTP status, `Content-Type` and raw body bytes.

Run: `python3 parity/parity.py --vm http://localhost:8083 --platform http://127.0.0.1:18083 --out parity/results/run1`

**Result: 19/19 cases equal. Normalisations: none.**

Raw bodies per side are in `results/run1/vm/` and `results/run1/platform/`; `results/run1/summary.json` has
status, content type, body SHA-256 and the `open_now` values per case.
